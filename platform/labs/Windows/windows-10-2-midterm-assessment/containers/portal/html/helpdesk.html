Common Issues

  • Password reset: Use the self-service portal or contact IT Support
  • VPN connectivity: Ensure WireGuard client is updated to v2.x
  • Printer issues: Restart print spooler; if unresolved, submit a ticket
  • Email sync: Verify Outlook profile is connected to Exchange server

New Employee — Document Management Access

All new employees receive temporary access to the firm's document management system during onboarding. Use the credentials below to access shared case files until your personalized account is provisioned (typically within 48 hours).

System Username Password Notes
Document Server (SMB) paralegal Summer2024# Connect to the cases share
Document Server (FTP) anonymous no password Read-only access to archived-cases

Archived Case Files: Until your personal account is provisioned, you can access the Document Server’s archived case repository via FTP using the anonymous login (no password required). This provides read-only access to archived cases, onboarding templates, and departmental handoff materials from 2025 and earlier.

Important: These are shared temporary credentials. Contact IT Support within 48 hours of onboarding to receive your personalized account. Do not use shared credentials for sensitive case files.

Network Resources

The firm's internal network includes the following systems. All systems are accessible from the internal network or via VPN.

  • Client Portal: Web-based intranet for firm announcements and resources
  • Document Server: Shared file storage for case documents and templates
  • Case Management: LDAP-integrated directory and case tracking system

Requesting Access

To request access to additional systems or elevated permissions, submit a ticket to IT Support with your department, role, and the specific resource you need access to. Requests are typically processed within one business day.
