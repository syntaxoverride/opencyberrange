FinanceCorp Network Topology (internal)

This subnet contains multiple hosts. Discover live hosts with a subnet scan, then identify each by its services:

- One host runs a web portal (HTTP on standard and alternate ports).
- One host is a file server offering FTP (anonymous access), SMB (guest share), and SSH on a non-standard port.
- One host is a domain controller with LDAP, RDP, SMB, and related services. The server string in SMB enumeration contains critical deployment information.

Do not assume IP addresses; enumerate the subnet and identify machines by open ports and service banners.
