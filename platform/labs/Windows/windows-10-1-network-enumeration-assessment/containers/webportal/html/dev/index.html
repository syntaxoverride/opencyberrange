Network Infrastructure Documentation Internal

This documentation covers the current network segment topology. It is maintained by the Infrastructure Engineering team and updated after each migration phase.

Subnet Overview

Multiple hosts exist on this network segment. Each machine serves a distinct role within the FinanceCorp infrastructure:

  • ◆Web Portal — Corporate intranet application running HTTP on standard and alternate ports
  • ◆File Server — Centralized file storage providing FTP, SMB, and SSH access for department shares
  • ◆Domain Controller — Active Directory services including LDAP, RDP, SMB, and Kerberos authentication
Migration Status

Phase 2 of the infrastructure migration is complete. IP addresses have been reassigned as part of the subnet reorganization. Refer to discovery scanning output rather than hardcoded addresses — the allocation may change during Phase 3.

⚠️ Note: Some services are running on non-standard ports during the migration period. Verify connectivity using service discovery rather than assuming default ports.
Access Policies
  • ◆The file server permits anonymous FTP access to the public repository
  • ◆SMB guest shares are enabled for cross-department file transfers
  • ◆SSH on the file server uses a non-standard port (documented in IT runbooks)
  • ◆The domain controller SMB banner contains deployment metadata for service identification
