    Meridian Energy Group - Admin Takeover

    The Engagement So Far

    Three chapters of reconnaissance, web exploitation, and infrastructure attacks have built a comprehensive picture of Meridian Energy Group's security posture. You have mapped the network, compromised the employee portal, exploited path traversal on the file server, chained API vulnerabilities on the SCADA monitoring system, and recovered credentials from multiple internal services.

    One target remains: the IT administration portal. Protected by LDAP authentication and accessible only to senior staff, the admin portal controls user provisioning, system configuration, and report generation for the entire Meridian Energy network. Behind it sits the engineering database, which stores SCADA controller configurations, maintenance schedules, and operational secrets.

    Capstone: Full Attack Chain

    The final exercise in the Meridian Energy engagement is the longest and most complex. It requires chaining four distinct vulnerability classes across four systems in a single attack sequence. There are no shortcuts and no isolated steps. Each phase depends on information extracted from the previous one.

    The chain:

    1. LDAP Injection bypasses authentication on the admin portal using a wildcard password
    2. Server-Side Template Injection (SSTI) in the report generator provides arbitrary code execution on the admin server
    3. Credential Discovery through environment variable leakage reveals engineering database credentials
    4. Lateral Movement to the engineering database extracts the master flag from a PostgreSQL table

    Each technique maps to real-world attack patterns documented in MITRE ATT&CK. Energy sector breaches frequently involve exactly this progression: initial access through authentication bypass, execution through application-layer vulnerabilities, credential access through configuration leakage, and lateral movement to operational technology databases.

    Systems in Play

    System Hostname Role
    Admin Portal admin.meridian-energy.corp IT administration, user management, reports
    LDAP Server ldap.meridian-energy.corp Directory services, authentication backend
    Engineering DB eng-db.meridian-energy.corp SCADA configs, maintenance data, secrets
    Corporate DB db.meridian-energy.corp HR records, employee data

    Difficulty: Expert

    The admin takeover exercise is rated expert difficulty. It requires:

    • Understanding of LDAP query syntax and injection techniques
    • Knowledge of Jinja2 template syntax and Python sandbox escapes
    • Familiarity with PostgreSQL command-line tools
    • Ability to chain multiple vulnerabilities without explicit guidance between phases
    • Careful observation of error messages, response headers, and application behavior

    Capstone Approach

    The capstone exercise provides the full walkthrough, but the real challenge is connecting the phases yourself. Before reading each phase, try to determine the next step based on what you have discovered so far. The best penetration testers do not follow scripts. They follow evidence.
