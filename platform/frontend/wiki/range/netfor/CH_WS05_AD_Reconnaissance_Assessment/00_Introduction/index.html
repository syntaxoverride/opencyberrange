    Chapter WS05: AD Reconnaissance Assessment

    The Capstone Assessment

    Active Directory (AD) reconnaissance is not a single technique; it is a discipline that weaves together DNS (Domain Name System) queries, LDAP (Lightweight Directory Access Protocol) enumeration, SMB (Server Message Block) share access, and Group Policy Object (GPO) analysis into a coherent picture of a domain environment. Chapters WS01 through WS04 introduced each of these techniques individually, building your skills one protocol at a time. Chapter WS05 asks you to combine everything into a single thorough assessment against a live AD environment.

    A capstone assessment differs from a guided exercise in one critical way: you decide the methodology. No step-by-step instructions tell you which tool to run next or which flag to look for first. Instead, you receive a target domain, a set of credentials, and a mission; find all three parts of a split flag hidden across different AD data sources. The techniques you need are the same ones you practiced in previous chapters, but the order, the troubleshooting, and the analysis are entirely up to you.

    The flag for the assessment is split into three parts, each stored in a different data source. You will need to query DNS records, search LDAP attributes, and access SMB shares to recover all three parts and assemble the complete flag. The split-flag design mirrors real-world scenarios where intelligence about a target is scattered across multiple protocols and services.

    WS02 LDAP Deep Dive Organizational Unit (OU) enumeration, user and group discovery, computer object listing, password policy extraction
    WS03 DNS Infrastructure SRV record queries, conditional forwarder discovery, DHCP (Dynamic Host Configuration Protocol) scope analysis, network topology mapping

LDAP searches from WS01 and WS02 expose user attributes and organizational structure. SMB access from WS01 and WS04 grants file retrieval from shares. GPO review from WS04 provides configuration and policy context.

    How the Multi-Part Flag Works

    The assessment flag follows the standard OCR{...} format, but the content is split into three segments stored in three different locations. Each segment is a standalone string that makes no sense on its own; only when you concatenate all three parts in the correct order does the complete flag emerge.

    LDAP["LDAP User Attribute<br/>Part 2"]
    SMB["SMB Share File<br/>Part 3"]
    FLAG["Complete Flag<br/>OCR{part1+part2+part3}"]

    You do not need to find the parts in any specific order. Each part is independent, stored in a different protocol's data, and retrievable with a different tool. The assessment tests whether you can identify which tool and technique to use for each data source.

    The Four Pillars of AD Reconnaissance

    The assessment covers four core reconnaissance techniques. Each technique targets a different layer of the AD infrastructure, and together they provide full visibility into the domain environment.

    DNS Reconnaissance reveals the naming infrastructure of the domain; hostnames, IP addresses, service locations, and custom records that administrators may have created. Forward lookups resolve names to addresses, reverse lookups map addresses back to names, SRV records identify domain controllers and key services, and TXT records sometimes contain metadata or configuration strings.

    LDAP Enumeration exposes the directory structure; users, groups, computers, OUs, and the attributes attached to each object. Every AD object has dozens of attributes, and administrators sometimes store sensitive information in fields like description, info, or comment that are readable by authenticated users.

    SMB Share Analysis provides access to files stored on domain-joined systems. Anonymous shares may expose public documents, while authenticated shares can contain internal tools, scripts, configuration files, and assessment data. Both access levels are worth testing.

    GPO Review reveals the policies applied across the domain; password requirements, software restrictions, logon scripts, and security configurations. The SYSVOL share on domain controllers stores GPO templates and scripts that are readable by any authenticated domain user.

    Assessment Methodology Checklist

    The checklist below outlines the reconnaissance areas you should cover during the assessment. The checklist is not a step-by-step guide; you decide the order and the specific commands based on what you discover along the way.

    DNS Reconnaissance:

    DNS reconnaissance covers the discovery of hostnames, IP addresses, service records, and any custom TXT entries within the target domain. These queries form the foundation of the assessment by revealing the naming infrastructure and service topology.

    • Perform forward lookups for key hostnames in the domain
    • Perform reverse lookups for discovered IP addresses
    • Query SRV records for domain controller and service locations
    • Check for TXT records on assessment-related subdomains
    • Document all discovered DNS entries

    LDAP Enumeration:

    • Query the base Distinguished Name (DN) and domain structure
    • Enumerate OUs for any assessment-specific containers
    • Search for user objects and examine non-standard attributes
    • List group memberships and computer objects
    • Review password policy settings

    SMB Share Analysis:

    SMB share analysis tests both anonymous and authenticated access to file shares on domain-joined systems. The goal is to discover accessible shares, map permission levels, and retrieve any files that contain assessment data or sensitive information.

    • Test anonymous access to all discovered shares
    • Test authenticated access using provided credentials
    • List and retrieve files from accessible shares
    • Review file contents for flag data and configuration details

    GPO and SYSVOL Review:

    GPO and SYSVOL review examines the group policy configurations and supporting files stored on the domain controller. The review uncovers security policies, logon scripts, and configuration templates that reveal how the domain is managed and secured.

    • Access the SYSVOL share on the domain controller
    • Enumerate GPO names and settings
    • Review logon scripts and policy templates
    • Document any security-relevant configurations

    Flag Assembly:

    After completing all reconnaissance phases, assemble the flag parts collected from each data source. Verify that each part is recorded accurately and that the final assembled flag conforms to the expected format.

    • Record each flag part with its source
    • Concatenate all parts in order
    • Verify the complete flag matches the OCR{...} format
    • Submit the flag on the platform

    Before You Start

    Make sure the following prerequisites are met before beginning the assessment.

    • You have completed Chapters WS01 through WS04 and are comfortable with DNS, LDAP, SMB, and GPO techniques
    • You understand how to use dig, nslookup, ldapsearch, smbclient, and smbmap
    • You have the assessment credentials: guest.user / Guest2024#
    • Your VPN connection to the Open Cyber Range is active
    • You can resolve dc01.corp.ocr-range.lab from your Kali terminal
    • You have a text editor or notes file open to record findings as you go
    • You have reviewed the methodology checklist above and have a plan for your approach

    The assessment has a suggested duration of 90 minutes. Allocate roughly 20 minutes for DNS reconnaissance, 25 minutes for LDAP enumeration, 20 minutes for SMB analysis, and 25 minutes for GPO review and flag assembly. Adjust the time allocation based on your comfort level with each technique.

    If you get stuck during the assessment, a detailed walkthrough is available in the exercise file. Try to complete as much as you can independently before consulting the walkthrough; the goal is to test your ability to apply techniques without step-by-step guidance.
