    CH_MEG01: Chapter Review

    What You Learned

    Over two exercises, you performed a complete external reconnaissance engagement against Meridian Energy Group's DMZ infrastructure. The progression followed the same methodology that professional penetration testers use when assessing energy sector clients.

    Exercise Phase Core Skill
    MEG1.1 Network Discovery Host discovery, service version scanning, FTP anonymous access, file extraction
    MEG1.2 Web Application Recon Virtual host enumeration, information disclosure, default credential testing, IDOR exploitation

    The attack chain demonstrates how reconnaissance findings compound: service scanning revealed a web server and FTP server, the web server exposed employee names and an internal status page, the status page disclosed the HR portal, employee names enabled credential guessing, and valid credentials exposed the entire employee database.

    Command Cheat Sheet

    Command Purpose Exercise
    nmap -sn <subnet>/24 Ping sweep to discover live hosts MEG1.1
    nmap -sV -p- <target> Full port scan with version detection MEG1.1
    gobuster dir -u <url> -w <wordlist> Brute-force web directories MEG1.1
    curl -s http://<target>/robots.txt Check for disallowed paths MEG1.1
    ftp <target> Connect to FTP server MEG1.1
    echo "<ip> <host>" \| sudo tee -a /etc/hosts Add hostname to local DNS MEG1.2
    curl -s -c cookies.txt -d "..." <url> -L POST login and save session cookie MEG1.2
    curl -s -b cookies.txt <url> Access authenticated pages with saved cookie MEG1.2
    curl -s <url> \| grep -o "OCR{[^}]*}" Extract flag from HTTP response MEG1.2

    Connect the Dots: What Comes Next

    The reconnaissance phase established multiple footholds into Meridian Energy Group's infrastructure. In Chapter 2, you will leverage these footholds to attack the company's web applications directly.

    Three attack types await you:

    1. SQL Injection (MEG2.1) - The employee portal search function concatenates user input into database queries. You will exploit the injection point to extract sensitive data from the backend PostgreSQL database.

    2. JWT Authentication Bypass (MEG2.2) - The HR portal uses JSON Web Tokens with a weak signing secret. You will crack the secret, forge an admin token, and access the internal API.

    3. Stored XSS (MEG2.3) - The IT helpdesk does not sanitize ticket content. You will inject JavaScript that steals the admin's session cookie when they review your ticket.

    Each attack builds on the credentials, hostnames, and knowledge you gathered during reconnaissance. The employee names you recorded will appear again as portal accounts. The default password pattern you discovered applies to additional systems. Every finding from Chapter 1 feeds forward into Chapter 2.

    Self-Assessment Answer Key

    1. The -sn flag tells nmap to perform host discovery only, sending ICMP echo requests and TCP probes without scanning any ports.

    2. The robots.txt file contains Disallow directives listing paths that search engine crawlers should not index. Penetration testers use it as a roadmap to sensitive directories.

    3. A virtual host is a web server configuration that serves different applications based on the Host HTTP header. When a browser sends a request, the server reads the Host header and routes the request to the matching application. Multiple websites can share a single IP address through virtual hosting.

    4. The username anonymous with an empty password (or an email address as the password) is the conventional method for anonymous FTP access. The server grants access to a restricted public directory.

    5. Insecure Direct Object Reference (IDOR) falls under A01:2021 - Broken Access Control in the OWASP Top 10. The application fails to verify that the authenticated user is authorized to access the specific resource they requested.

    6. The /internal/status endpoint exposes internal hostnames, application versions, and service dependencies. Without authentication, any attacker who can reach the web server gains a detailed map of internal infrastructure, reducing the effort needed to discover additional attack surfaces.
