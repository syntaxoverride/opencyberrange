    Meridian Energy Group - Network Reconnaissance

    The Engagement

    Meridian Energy Group is a mid-size oil and gas company operating three refineries and a pipeline network spanning four states. After an industry-wide advisory from CISA warned of increasing cyberattacks against the energy sector, Meridian's CISO authorized a full-scope penetration test of the company's external-facing infrastructure.

    You have been engaged as the lead penetration tester. Your rules of engagement permit active scanning, credential testing, and exploitation of any systems in the designated DMZ segment. Meridian's security team is aware of the engagement but has not been told the specific timing or targets.

    The Network

    Meridian's DMZ hosts three externally accessible servers:

    flowchart TD
    Internet["Internet"] --> FW["Firewall / VPN Gateway"]
    FW --> WWW["www.meridian-energy.corp<br/>Corporate Website<br/>Port 80/443"]
    FW --> MAIL["mail.meridian-energy.corp<br/>Mail Server<br/>Port 25/110/143"]
    FW --> FILES["files.meridian-energy.corp<br/>File Server<br/>Port 21/22"]

    WWW --- DMZ["DMZ Segment"]
    MAIL --- DMZ
    FILES --- DMZ
    Server Hostname Role
    Corporate Website www.meridian-energy.corp Public-facing site with company info, investor relations, employee directory
    Mail Server mail.meridian-energy.corp Handles corporate email for all three refineries
    File Server files.meridian-energy.corp FTP/SFTP server for partner document exchange

    These three servers represent Meridian's external attack surface. Internal systems (SCADA, pipeline monitoring, refinery control) sit behind additional network boundaries and are out of scope for the initial reconnaissance phase.

    What You Will Learn

    By the end of this chapter, you will be able to:

    • Perform systematic network reconnaissance against a corporate DMZ
    • Identify services and software versions across multiple hosts
    • Enumerate web directories and discover hidden content
    • Access anonymous FTP shares and extract sensitive files
    • Identify employee information useful for later attack phases
    • Map the relationship between public-facing services and internal infrastructure

    Prerequisites

    • Your Kali VM must be connected to the lab VPN
    • Familiarity with basic nmap scanning (host discovery, service version detection)
    • Familiarity with curl for HTTP requests
    • Familiarity with ftp command-line client

    Two Ways to Work

    Each exercise supports two modes:

    Walkthrough mode - Read the full step-by-step solution. Every command is shown, every output is explained.

    Independent mode - Read only the Objective, Tools, and Flag Progress sections, then work on your own. Hints unlock progressively if you get stuck.

    The walkthrough is always there if you need it, but try independent mode first. That is where the real learning happens.
